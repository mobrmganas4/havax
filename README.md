# 🎮 لعبة تكسير الطوب الملحمية (Epic Brick Breaker)

لعبة ويب تفاعلية مذهلة تعمل مباشرة من المتصفح بدون أي مساحة تخزين أو تحميل، مصممة خصيصاً لتُرفع بسهولة على **GitHub Pages**.

## 🌟 مميزات اللعبة:
* جميع الملفات (بما فيها الصورة `logo.png`) موجودة في المجلد الرئيسي بجانب `index.html` لسهولة الرفع على غيت هاب.
* تصميم عصري جذاب مع واجهة مستخدم متطورة (UI/UX) باستخدام Google Fonts (Cairo).
* تدعم اللعب عبر الكمبيوتر والهواتف الذكية.

---

## 🚀 كيفية الرفع على GitHub:
1. فك ضغط ملف الـ `zip`.
2. أنشئ مستودعاً جديداً (Repository) على GitHub.
3. ارفع جميع الملفات الموجودة داخل المجلد مباشرة (بدون مجلد فرعي للصور) إلى المستودع.
4. من Settings > Pages، فعّل العرض من فرع `main`، ومبارك عليك الموقع أونلاين!
